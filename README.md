# todo-cli

A tiny command-line to-do list written in Python (standard library only).

## Purpose
Mini project for the Software Maintenance course (Lab 7 final project) to practice
the Git feature-branch workflow: branches, commits, merges and GitHub.

## Key features
- Add tasks
- List tasks
- Mark tasks as done
- Clear finished tasks (`python todo.py clear`)
- Tasks are saved to `tasks.json`

## Usage
```bash
python todo.py add "Buy milk"
python todo.py list
python todo.py done 1
python test_todo.py   # self-check
```
